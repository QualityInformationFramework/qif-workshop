#   py -3.13 -m venv venv              (Linux/macOS: python3.13 -m venv venv)
#   venv\Scripts\Activate.ps1          (Linux/macOS: source venv/bin/activate)
#   pip install -r requirements.lock

# Install from this file only when changing dependencies (then regenerate the
# lock; see its header), or on Python 3.11, which the lock does not support.

# Python: 3.13 recommended. 3.11 is the floor for this file (pandas 3 requires
# it) and 3.12 for the lock (its numpy pin has no older wheels). 3.13 is the
# ceiling, because the mesher needs `triangle`, which has no cp314 wheel and will
# not build from source on 3.14. The notebook side alone runs on 3.14, but the
# pipeline as a whole does not.
# Expect ~1.4 GB on disk and a few minutes. VTK alone is 639 MB (monolithic
# wheel, no slim variant) and scipy adds ~110 MB.
